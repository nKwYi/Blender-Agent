交互实际发生在哪里

  • Blender 侧没有任何输入框、没有转录、没有进度；它只是 socket 服务端开关 + 资产站 Key。
  • 对话在 Claude/Cursor 那一侧。它真正厉害的是聊天侧组件：把实时视口画面嵌进聊天窗口（可刷新、AI 改完自动重截、点物体即把它作为上下文附上）+ 资产缩略图选择器。
  • 默认AI 可直接跑任意 Python，无审批；可选 BLENDER_MCP_SAFE_MODE=1 走服务端 AST 白名单。
  • 视口回传用 screen.screenshot_area + render.opengl，支持多角度/线框/X 光。

为什么它是主参照

  • 直连 DeepSeek（OpenAI 兼容），无 MCP、无桥，跑在 Blender 5.2.2 上 —— 和我们的技术选型一模一样。
  • 输入用 box.textbox(settings,"prompt_text", initial_visible_lines=3, placeholder="Ask Blender...")。我在你本机 5.2.1 实测这个 API 存在、参数名一致（也纠正了我上一轮的说法：5.2 的 StringProperty 没有 MULTILINE 子类型，但多行框在布局侧）。
  • 忙态：progress(type='RING') + 已耗时秒数，Stop 和 Send 复用同一个按钮位。
  • 撤销回执盒：标题 Undoable / Not undoable，内容 objects: 17 → 18；全局撤销关掉时直接禁止发送并给按钮。
  • 工具行用图标走状态 TIME → ERROR → CHECKMARK，代码块折叠成 <用途> · N 行 可展开；转录与代码镜像成两个文本块（Copilot Transcript / Copilot Code）方便复制。
  • 上下文预算条 + ⓘ 弹窗里再给一条，带 Compact / Restore。
  • 流式：SSE → 子进程 ndjson → bpy.app.timers 0.05 秒 tick，只在变化时 redraw；历史按 .blend 路径存 JSON（200 条 / 1 MiB 上限）。
  • 错误盒子正文折行成 label，因为它实测 Blender 会把过长 label 从中间裁掉。
  • 诚实文案：README 明写 Stop 杀不掉正在跑的 bpy 调用；也明写"模型看不见视口、UI、任何渲染"。

诚实评估

  • 该有的信息其实都有了（轮次、耗时、token、缓存命中、每步成败），问题是全糊成一段纯文本，没有层级、没有状态色、不能展开看返回。
  • 最致命的不是外观，是没有多轮历史：每点一次"执行"都是一次全新对话，模型看不见你上一句说了什么，也记不住它自己刚改了什么。
  • 执行期间界面直接卡死且没有任何"正在忙"的视觉证据，用户会以为崩了（这是文档 §5 选的同步方案，不是 bug，但界面必须说实话）。
  • 没有停止、没有撤销回执、没有出错重试；模型也看不见视口。
注意：图标名 PREFS / DOC / NETWORK / TOKEN 在 5.2 不存在（我踩过，写错会让整块面板从那一行起静默截断）。可用的是 PREFERENCES / TIME / CHECKMARK / ERROR / CONSOLE / FILE_SCRIPT / FUND。

缺口 → 方案 一览

P0 · 只改 ui.py 一个文件
  • 单行输入 → textbox(initial_visible_lines=3, placeholder=…)。Enter 是否提交需实测（HUD 那套是它自己 modal 手写按键，textbox 未必带）。
  • 无忙态 → progress(RING) + 秒数 + Send/Stop 同位。
  • 工具调用糊成文本 → 图标状态行 + 可展开返回。
  • 错误混在回复里 → 独立 alert 盒 + 重试。
  • token 藏着的 → 预算条 + 百分比。
P1 · 要加一点逻辑
  • 多轮历史（真正的功能缺口）：按 .blend 路径存 JSON，参考 copilot 的 200 条 / 1 MiB 上限。
  • 可撤销回执 objects: N → M：execute_tool 前后各数一次。
  • 转录镜像成文本块，解决"看得见复制不出来"。
  • 视口截图回传给模型：让 AI 从盲改变看着改。注意本机无头渲染全黑、render.opengl 无头直接报错，只能在有 GUI 时用，要设计降级。
P2 · 抢眼但贵
  • UIList 气泡转录（ultra）：比 label 优雅，要维护 CollectionProperty + "在底部才自动滚"。
  • 还原点列表（blendrelay Versions）：属完整版 Phase 5。
  • 视口 GPU HUD 命令条（blendrelay）：几百行手写绘制 + 命中测试，与最小闭环冲突。
许可：copilot 无 LICENSE 文件、blendrelay 插件部分是 GPL-3.0，而我们 manifest 写的是 MIT —— 只能抄交互思路，不能粘代码。
证据强度说明。 标"已实测"的是我或子代理直接读到源码行号、或在你本机 5.2.1 上跑过探针核实的：textbox 参数名、progress 的 BAR/RING 枚举、图标名集合（PREFS/DOC/NETWORK/TOKEN 不存在）、blendrelay 的 AF_OT_ViewportHUDModal 与它的 modal/gpu 绘制细节、ahujasid 面板 draw() 在 addon.py:5864-5982、copilot 面板在 panel.py:909-1537。
