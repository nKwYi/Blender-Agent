Blender 5.2.1 实测 · blender_deepseek_agent

只用 Blender 允许的 API，面板能做到什么程度

下面每一块面板的颜色、圆角、高度，都取自你本机 bpy.context.preferences.themes[0] 的实时读数，不是目测调的。 结构上只使用 UILayout 真正开放的能力——没有任意 RGB、没有自定义字体、没有 hover 态、没有阴影。

圆角是免费的——Blender 5 的 panel_roundness = 0.4，你的面板天生就是圆角，和设计稿的 3–5px 几乎一致，之前把它列进"做不到"是误判。 你设计稿的主色 #4772b3 就是 Blender 的 panel_active，配色本来就是照着 Blender 主题抄的。 真正的差距只有一条：Blender 主题里有绿色 #188625 和琥珀 #ac8737，但 Python API 只暴露了 alert 一个状态——所以界面上只能有红色，别的语义色只能待在主题里。

六个关键状态

当前 ui.py 只用了 box / alert / scale_y / separator 四样。 下面这版额外用上了 layout.panel()、use_property_split、emboss='NONE'、separator_spacer() 和 progress()—— 全部在实测的 UILayout 接口清单里，没有一个是编造的。

哪些能做，哪些真的做不了

「Blender 有」和「插件能拿到」是两件事。 Blender 5.2.1 主题里存在绿色 #188625 和琥珀 #ac8737，但 UILayout 只暴露了 alert 一个状态位—— 主题里有，Python 调不到，这是下面这张表里最容易被误判的一格。

设计稿想要Blender 5.2.1 实测插件能设置说明
圆角 3–5px panel_roundness = 0.4 继承 主题层已默认圆角，你的面板天生就是圆角。改不了单个控件，但不用改——直接接受 Blender 的就是设计稿要的。
主色 #4772b3 panel_active = #4772b3 是 激活态、选中态、滑块填充全部是这个蓝。设计稿配色本来就是从 Blender 主题抄的。
成功绿 #7cb87c wcol_state.success = #188625 否 主题里有，UILayout 不给访问。只能用 alert 的反面——即"什么都不做"。
警告橙 #ed9a21 wcol_state.warning = #ac8737 否 同上。想区分"失败"和"注意"，只能靠图标和文案，不能靠颜色。
错误红 #e0716a wcol_state.error = #991616 是 box.alert = True，全 UI 唯一的红。建议只留给 FAILED。
次要文字灰 wcol_tab.text = #989898 近似 enabled=False 得到灰化，但那是"禁用"语义。层次感只能靠缩进和空行拉开。
字体 / 字号 / 字重 label() 无相关参数 否 label() 只有 text / text_ctxt / translate / icon / icon_value 五个参数。
hover 态 wcol_*._inner_sel 是 selected 部分 Blender 内部有 hover 配色，但插件只能在 enabled / active 之间切，不能让鼠标经过变色。
box-shadow 层次 仅 menu_shadow_fac 作用于菜单 否 面板没有阴影。层次只能靠底色明度差（#3d3d3d 面板 vs #1d1d1d 内盒）。
可滚动长列表 侧栏滚轮实测不滚动 否 最致命的一条。超屏内容用户根本够不到，必须靠 layout.panel() 折叠或分页消化。
扁平按钮 emboss 枚举含 NONE 是 layout.emboss = 'NONE' 或 operator(emboss=False)，最接近 Figma flat 的一个开关，当前代码用量为 0。
规范两列属性 use_property_split : BOOLEAN 是 Blender 自家面板到处在用，一行代码的事，当前代码用量为 0。
可折叠子面板 layout.panel(idname, default_closed, layout_header, layout_body) 是 原生折叠箭头 + 正确动效，替换现在手搓的"收起^"按钮。
进度条 / 流式 layout.progress()、wcol_progress 是 控件已存在，但 agent.py:230 写死 stream: False，所以现在没东西可推进度。

把这版做出来要改什么

全部落在 ui.py，不动 worker.py 的线程协议，不引入任何 pip 依赖。

5 分钟

1 行

扁平按钮

1 行

layout.emboss = 'NONE'。去掉按钮顶部的高光渐变，是当前画面离 Figma 最近的单一改动。

半天

用 layout.panel() 替换手搓的"收起^"折叠，拿到原生箭头、展开动效和正确的层级。
