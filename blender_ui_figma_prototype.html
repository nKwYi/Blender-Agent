AI 对话详情设置

1AI 消息去框，用户消息留框

AI 回复直接落在面板底色上，只有头像行和正文，视觉上"轻"；用户消息保留深色框并右缩进， 一眼能分清谁说的话。

对比参考：MiniMax Code 的会话流就是这个处理——机器人的话不加容器。

2输入框右下角可拖动拉伸

右下角做了斜纹把手，按住上下拖就能拉高输入框，鼠标悬停出现"拖我拉高"提示。 换长需求时可以拉成六行，不必分多条发。

试试：把鼠标移到输入框右下角 ↘ 纹路上，按住往下拖。

3去掉确认步骤 + 确认 / 按推荐来

删掉了原来的「AI 复述需求 → 更改 / 确认并开始建模」整段，选完直接建模，少一次来回。 三组选项底部给了两个按钮：确认选择用你当前选的，按推荐来一键把三组都跳到推荐项。

试试：先随便改几项，再点「按推荐来」，选中状态和下方提示会一起变。

4结果区横向四 tab + 可折叠

新增对象 / 参数详情 / 脚本摘要 / 归档信息收成一条横排 tab，切换后下方整块替换。 「新增对象」额外加了折叠条，列表长的时候可以整块收起，只留一行标题。

试试：点「参数详情」切 tab，再点对象列表上方的「收起」。

5取消翻页，改纵向无限滚动

中间会话区改成可滚动容器，内容再长也不会把面板撑爆。底部输入区固定不动， 滚消息时随时能接着输入——这比翻页顺手。

试试：在中间区域滚轮上下滚，或直接拖右侧滚动条。

6思考动效挂在 AI 头像位置

AI 思考时头像位置变成三点跳动，外面套一圈扩散脉冲，「正在思考」紧跟在「AI 助手」后面。 耗时也挪到了同一行紧贴助手名，不再飘到最右边。

看用户第二条回复下面那条——头像在跳。

7输入框回弹已修

上一版松手时把高度重置回 auto，所以一松手就弹回去。现在拖到多高就停在多高， 下次发送完才恢复。四个按钮文案也统一成四个字：发送指令 / 回退发送 / 新建任务 / 清空记录。

试试：拉高输入框后松手，高度应该保持住。

配色沿用 Blender 5.2.1 实测主题值；控件高度与间距为估算。本页为设计原型，尚未实现—— 单选、拉伸、tab 切换、滚动在浏览器里都是真交互，可直接试用。
